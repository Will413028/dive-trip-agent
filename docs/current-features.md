# 功能概覽

給想試玩或了解作品能力的讀者。最後核對：2026-10-01。

**Dive Trip Agent 目前提供本機離線 DEMO：你可以編輯潛旅行程、確認修改、試算預算、復原版本及分享快照。服務尚未公開上線；真模型規劃仍在實驗中。**

## 適用範圍

小琉球、綠島、墾丁；每趟一個目的地，1–6 人、2–7 天，費用以 TWD 顯示。主要資料為合成 DEMO，價格、開放時間及可訂狀態不能當成實際旅遊資訊。

## 現在可以做什麼

狀態定義：**本機可用**＝可在離線 DEMO 操作；**實驗中**＝尚未完成品質驗收；**未提供**＝目前沒有供使用者使用。

| 功能 | 狀態 | 你可以做什麼 |
| --- | --- | --- |
| 建立行程與編輯需求 | 本機可用 | 開啟示範行程，調整目的地、人數、潛水／非潛水分配、日期或天數、預算、住宿偏好與步調 |
| 查看目的地與活動 | 本機可用 | 查看精選目錄，挑選目前目的地的活動；沒有即時全網搜尋 |
| 編輯每日行程 | 本機可用 | 新增、移除或替換活動，移動日期與時段，修改住宿房數；沒有拖曳排序 |
| 鎖定重要項目 | 本機可用 | 鎖定內容、日期與費用依據；修改前先解鎖並確認 |
| 檢查並確認修改 | 本機可用 | 查看差異、費用變動與衝突，再接受或拒絕；確認前行程不變，過期提案須重算 |
| 試算預算 | 本機可用 | 查看已知小計、未知費用與排除項目；未知不當零，示範價格保留 DEMO 標示 |
| 對話操作 | 本機可用 | 用固定示範情境體驗工具進度、回答與確認流程；不宣稱理解任意自然語言 |
| 保存與復原 | 本機可用 | 刷新後讀回已保存內容及待確認狀態；把舊版內容復原成新版本，保留歷史 |
| 查看地圖 | 本機可用 | 點擊載入有已核對座標的項目；缺座標顯示待確認，不推估路線或交通時間 |
| 分享與撤銷 | 本機可用 | 先預覽公開欄位，再建立唯讀快照連結；不包含私人對話，後續修改不會同步分享，可撤銷 |
| 刪除行程 | 本機可用 | 確認後立即封鎖行程與分享，查看「刪除中」與「已刪除」狀態 |
| 匿名使用 | 本機可用 | 不需註冊；預設保存期限 30 天，不承諾跨裝置恢復 |
| 桌面與手機版面 | 本機可用 | 桌面並列對話與工作台，手機版面可切換對話、需求與行程 |
| 真模型規劃 | 實驗中 | 正在驗證模型能否理解需求並完成任務，一般工作台尚未開放 |
| 公開線上服務 | 未提供 | 目前須在本機啟動，沒有可公開試玩的服務網址 |

## 建議試玩流程

依 [本機啟動說明](../README.md#本機行程工作台) 啟動後：

1. 在首頁選「試玩一般規劃」，查看需求、每日行程與預算。
2. 在對話輸入固定示範指令「第二天下午留白」，或透過行程卡片提出修改。
3. 檢查提案差異與費用，按接受或拒絕；確認前查看原行程仍未改變。
4. 接受修改後刷新，確認保存內容；再用版本復原功能回到舊版內容。
5. 預覽分享欄位並建立快照，在同一本機服務查看唯讀內容，再撤銷連結。

另可試「試算目前預算」「把行程改為悠閒」「人數未定」「查詢目的地」。首頁也有預算衝突與明示靜態查詢失敗示範；`/case-study` 提供作品案例介紹。

## 使用前要知道

- 本機分享連結只能在可連到該本機服務的環境使用，不是公開託管服務。
- 少量景點名稱與座標經人工核對，價格、開放與可訂狀態仍待確認；預算試算不保證實際旅行費用。
- 行程刪除不重置使用額度，部分帳務與受保護評估證據依 [留存規則](retention.md) 保留。
- 本機互動已經離線測試驗證；模型效果、正式部署與實體手機的驗收範圍另見 [驗證紀錄](release-evidence.md)。

## 目前未提供的服務

預訂、付款、代寄訊息、保證名額、正式會員與跨裝置同步、多人協作、語音、原生 app、全球或跨目的地最佳化、無限制爬取，以及適潛／醫療／保險判斷與潛水安全背書。
